# JAM Trail 실기기 테스트 안내 (명세 9장 9단계)

시뮬레이터에서 확인한 본 데이터 필드를 fēnix 8에 올려 실제 트레일에서 씁니다.
시뮬레이터로는 확인할 수 없는 항목(명세 10.1의 8·9·10·11·13번)을 확인하고, 기본값(10.3)을 정하는 것이 목적입니다.

| 위치 | 내용 |
|---|---|
| `bin/JAMTRAIL.iq` | 스토어 업로드용 패키지. `scripts/build-app.sh`로 만듭니다 (GitHub Pages 서버, 시험 로그 끔) |
| `gpx/` | 코스 원본. 여기에 GPX를 올리면 GitHub Actions가 변환해 Pages에 배포합니다 |
| `https://standardmanual.github.io/589132427/` | 코스 서버. `index.txt`(코스 목록), `current.txt`(현재 코스) |

JAM Trail은 스토어에 베타로 등록해 둔 앱(처음에 시험 필드 "JAM Trail Test"로 올린 앱)의 **새 버전**으로 올립니다.
스토어는 등록한 앱 ID(`ec7e18be-…`)가 다른 파일을 새 버전으로 받지 않아서, 본 앱이 이 ID를 이어받았습니다.
시험 필드는 할 일을 마쳤고, 겹치지 않도록 새 ID로 바꿨습니다.

---

## 1. 스토어에 올리기

1. `https://apps-developer.garmin.com`에서 JAM Trail Test 앱을 열고 **새 버전 올리기**를 고릅니다.
2. `bin/JAMTRAIL.iq`를 **압축을 풀지 말고** 그대로 올립니다. 버전을 물으면 1.1.0(또는 이전보다 높은 값)으로 넣습니다. 앱 이름과 설명은 JAM Trail로 바꿔도 됩니다.
3. 개발자 키는 `jamtrail_developer_key.der`입니다. 스토어 앱은 처음 올린 키로만 업데이트할 수 있으니, 이후 버전도 `scripts/build-app.sh`로 만든 파일을 올리고 `app/manifest.xml`의 `version`을 올립니다.
4. 폰에서 시계를 동기화하면 JAM Trail Test가 JAM Trail로 바뀝니다. 시험 필드를 넣어 둔 데이터 화면에 그대로 JAM Trail이 나옵니다. 없으면 트레일런 활동 설정 → 데이터 화면 → 새 화면 추가 → **1필드 레이아웃** → Connect IQ 필드 → **JAM Trail**.

## 2. 코스 올리기

1. 달릴 코스의 GPX를 준비합니다. 고도(ele)가 들어 있어야 합니다.
2. 폰 브라우저로 `https://github.com/standardmanual/589132427`의 `gpx/` 폴더를 열고 **Add file → Upload files**로 올립니다. 모바일 화면에서 안 보이면 브라우저의 데스크톱 보기로 바꿉니다.
3. 몇 분 뒤 `https://standardmanual.github.io/589132427/index.txt`에 코스 이름이 보이면 배포된 것입니다. **가장 최근에 올린 GPX가 현재 코스**가 됩니다.
4. **같은 GPX를 Garmin Connect 코스로도 보내 시계에 넣습니다.** 활동 중 이 코스로 내비게이션을 하면 JAM Trail이 가민의 남은 거리로 위치를 정합니다(가장 정확, 명세 7.5 1순위). 내비게이션을 하지 않으면 GPS 좌표로 위치를 찾습니다.

지금 서버에는 가상 샘플 코스(강원도 좌표)만 있어, 실제 코스를 올리기 전에는 위치가 "코스 이탈"로 나옵니다.

## 3. 달리기 전날 (집에서)

1. 폰을 옆에 두고 블루투스를 켭니다. iPhone이면 **Garmin Connect 앱을 한 번 열어 둡니다**.
2. 트레일런 활동을 열고 JAM Trail 화면으로 넘깁니다. 시작 버튼은 누르지 않습니다.
3. 가운데 `코스 받는 중 n/N`, 끝나면 마지막 줄에 `새 코스 적용: <코스 이름> <km>`이 5초 보입니다.
4. 활동을 저장하지 않고 나옵니다. 받은 코스는 시계에 남습니다.

## 4. 설정 메뉴 (명세 5장)

활동 화면에서 설정 메뉴를 엽니다. fēnix 8의 정확한 경로는 확인이 필요합니다(10.1 8번). 포럼 설명으로는 **활동 중 UP 길게 누르기 → Connect IQ 필드 → JAM Trail**입니다. 활동 설정 → 데이터 화면에서 필드를 고른 뒤 설정이 보이는지도 확인해 주세요.

| 항목 | 값 | 기본 |
|---|---|---|
| 세로 배율 | 2×, 3×, 4× | 3× |
| 그래프 가로 범위 | 500 m, 1 km, 2 km, 5 km, 10 km, 구간 맞춤 | 2 km |
| 현재 경사 평균 구간 | 100, 200, 400 m | 100 m |
| 코스 이탈 임계값 | 30, 50, 100 m | 50 m |
| 경사 색상 | 켬, 끔 | 켬 |
| **진단 표시** | 끔, 켬 | 끔 |
| 코스 | 서버 현재 코스 따르기 / 저장된 코스 / 서버 목록의 코스 | 서버 따르기 |
| 코스 목록 새로고침 | 서버의 index.txt를 다시 받음 | |

**시험하는 동안은 진단 표시를 켜 주세요.** 마지막 줄에 다음이 나옵니다.

```
가민 12.34 · dtd 8210 · 코스 이름 · 38K
```

| 부분 | 뜻 |
|---|---|
| `가민` / `GPS` / `거리` | 위치를 정한 방법 (가민 코스 남은 거리 / GPS 좌표 매칭 / 누적 거리) |
| `12.34` | 코스 위치 (km) |
| `dtd 8210` | 가민이 준 목적지까지 남은 거리 (m). `-`면 값이 없음 |
| `(dtd=dtn)`, `(len 19404)` | 가민 값을 쓰지 않은 이유: 다음 지점까지 거리와 같음 / 가민 코스 길이가 저장 코스와 2% 넘게 다름 |
| 코스 이름 | 가민이 준 목적지 이름 (`nameOfDestination`) |
| `38K` | 남은 메모리 |

## 5. 트레일에서 확인할 것

화면 사진을 찍어 보내 주세요. 활동 기록(FIT)도 있으면 좋습니다.

| # | 확인 | 방법 | 명세 |
|---|---|---|---|
| 1 | 한글이 보이는가 | 모드 표시, 레이블, 하단 글자에 네모·빈칸이 없는지 | 10.1 13번 |
| 2 | 가민 코스를 따라갈 때 위치 | 코스 내비게이션 중 진단 표시가 `가민`이고 dtd가 줄어드는지, 코스 이름이 나오는지 | 10.1 9번 |
| 3 | 가민 코스 없이 위치 | 내비게이션 없이 활동을 열면 `GPS`로 바뀌고 삼각형이 실제 위치에 있는지 | 7.5 |
| 4 | 모드 전환 | 오르막·내리막·평지 표시가 실제 지형과 맞게, 새 구간으로 조금 들어간 뒤 바뀌는지 | 7.6 |
| 5 | 경사 체감 | 큰 숫자(현재 경사)와 그래프 기울기가 실제 체감과 맞는지. 세로 배율 2×·3×·4×를 바꿔 보기 | 10.3 |
| 6 | 코스 이탈 | 코스를 벗어나면 `! 코스 이탈 72 m`와 주황 테두리 삼각형이 나오고, 돌아오면 사라지는지 | 4.2 |
| 7 | 폰 없이 다음 활동 | 다음날 폰 블루투스를 끄고 활동을 열어도 코스가 그대로 나오는지 | 10.1 11번 |
| 8 | 설정 메뉴 | 여는 경로, 값을 바꾼 뒤 화면에 바로 반영되는지, 한글 표시 | 10.1 8번 |
| 9 | 배터리·버벅임 | 1시간 이상 쓰는 동안 화면 갱신이 끊기거나 필드가 멈추지 않는지 | 7.7 |

## 6. 결과를 보고 정할 것 (명세 10.3)

- 세로 배율 기본값 (지금 3×)
- 그래프 가로 범위 기본값 (지금 2 km)
- 현재 경사 평균 구간 기본값 (지금 100 m)
- 경사 색 팔레트 (3단계: 0–10 초록, 10–20 노랑, 20%+ 빨강 / 내리막 초록·하늘·보라)
- 그래프 영역을 더 키울지

## 7. 문제가 생기면

| 증상 | 확인 |
|---|---|
| `코스 없음` / `폰 연결 없음 (-104)` | 폰 블루투스, iPhone은 Garmin Connect 앱을 열어 둠 |
| `파일 없음 (404)` | `index.txt`에 코스가 있는지, Actions 배포가 끝났는지 |
| `응답이 너무 큼 (-402)` | 조각 크기 문제. 알려 주세요 (지금 6,000자, 실기기 한도 8–16 KB) |
| `코스 검증 실패` | 조각이 손상됨. 활동을 다시 열면 처음부터 다시 받습니다 |
| 필드가 `IQ!` 아이콘으로 멈춤 | 앱 오류. 사진과 함께 무엇을 하던 중이었는지 알려 주세요 |
